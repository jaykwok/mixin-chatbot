# 内容规划与检查

按读者真正需要作出的判断安排内容，以下是参考问题，可合并、调整顺序或省略无关项。

| 场景 | 内容应回答的问题 |
| --- | --- |
| 售前 | 客户要解决什么问题？资料中的哪些能力适用？如何部署？有哪些前提、限制和待确认事项？ |
| 交付 | 范围和责任是什么？实施前需要什么？怎样操作、验证、验收和回退？ |
| 售后 | 现象及影响是什么？有哪些日志或复现证据？哪些原因已证实、哪些只是推测？处理后怎样验证？ |

多资料成稿时，可在临时目录记录“目标章节或页面 / 来源文件与位置 / 沿用、修改或新增 / 待确认项”。这是工作记录，无需让用户审批每一行。查询和文件提取仍使用现有资料索引及 `document_extract`。

复用内容要检查适用产品与版本、单位、术语、前置条件、旧客户名称和项目承诺。生成的客户方案是本次交付物，不因此成为新的正式产品依据。

材料引用了未提供的报价表、版本说明或其他原件时，标明缺少的依据，不把转述当成已经核验。早期方案、发布计划和后续版本说明存在差异时，按实际适用条件表达，保留需要确认的事项。

编辑完成后核对用户指定的修改范围。组装后检查内容重叠、缺失衔接、编号和页码。视觉检查使用实际渲染图；仅凭文件能打开或文字提取成功，不能声称版式已检查。渲染器使用的字体可能与客户 Office 不同，应给文本留足空间。

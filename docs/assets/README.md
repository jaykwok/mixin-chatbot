## 核对管理台

在项目根目录执行：

```sh
bun run tui:preview overview 100 24 --plain
```

将输出与图片中的导航、指标、趋势、待办和底部键位逐项比较。去掉 `--plain` 可查看颜色；演示数据和渲染入口位于 [preview.ts](../../scripts/ops/tui/preview.ts)。该命令只输出文本，不生成 PNG，也不读取真实 `data/`。不带页面名时输出全部演示页（含会话列表 `history` 与会话详情 `history-detail`）；渲染时时钟固定在演示时刻，“几小时前”“几天前”不随运行日期变化，子页导航高亮当前页。

当前 `tui-overview.png` 截于总览改版之前（改版后有待处理事项时不再列常用入口，侧栏不再重复运行方式和端口），需按上面的方法重新捕获。

需要更新图片时，从同一渲染入口捕获 100×24 的画面，保留“演示数据”说明。不要手工改写截图中的界面文字或数值。

## 核对报表

报表生成逻辑位于 [report.ts](../../scripts/ops/tui/report.ts)。需要更新图片时，使用演示数据调用 `writeReport` 导出 HTML，在浏览器中打开后截图，保留与现有图片一致的内容范围。

当前图片只展示提问总量、各群提问次数、群概况和模型用量；完整报表还包含其他明细。替换图片后，在首页和[管理台指南](../tui.md#导出-html-报表)中检查清晰度与图注是否匹配。
